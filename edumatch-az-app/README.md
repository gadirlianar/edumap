# 📱 EduMatch WebApp & PWA (`edumatch-az-app`)

**Live URL:** [https://edumatch-az-app.vercel.app/](https://edumatch-az-app.vercel.app/)

Installable Progressive Web App (PWA) for **EduMatch**, featuring Liquid Glass navigation, live interactive classroom & whiteboard, lesson booking workflows, and student/tutor studios.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 🧪 Scripts

- `npm run dev` — Start local development server
- `npm run build` — Production build
- `npm run lint` — Run ESLint checks
- `npm test` — Run Vitest test suite
