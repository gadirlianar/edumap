# 🌐 EduMatch Website (`edumatch-az`)

**Live URL:** [https://edumatch-az.vercel.app/](https://edumatch-az.vercel.app/)

Main web application for **EduMatch**, featuring verified university mentor discovery, side-by-side tutor comparison, interactive city map filtering, diagnostic quizzes, and GTM strategy analytics.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 🧪 Scripts

- `npm run dev` — Start local development server
- `npm run build` — Production build
- `npm run lint` — Run ESLint checks
- `npm test` — Run Vitest test suite
